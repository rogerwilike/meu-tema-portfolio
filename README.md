# 💻 Front-End Portfolio — Roger Wilike

Personal web portfolio developed to showcase projects, technical skills, and software development experience. Hosted live via **GitHub Pages**.

🔗 **Live Demo:** [rogerwilike.github.io/meu-tema-portfolio](https://rogerwilike.github.io/meu-tema-portfolio/)

---

## 🚀 About the Project

A static, responsive, and high-performance web interface built with a focus on web development best practices, semantics, and accessibility. The site serves as a showcase for practical projects, learning milestones, and contact channels.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic and accessible markup
* **CSS3:** Modern styling, responsive design (Flexbox / Grid), and CSS variables
* **JavaScript:** DOM manipulation and dynamic behaviors
* **Deployment & Hosting:** GitHub Pages
